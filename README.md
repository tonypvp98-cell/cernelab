# PWA Hub Premium

Crie uma Vitrine / Hub de Produtos (Storefront) de alta conversão para exibir todos os aplicativos PWA do nosso ecossistema, com design premium Dark Tech (inspirado na Vercel e Linear.app).

Instruções Visuais e de Design:

- Tema geral: Escuro (#0D0D0D) com contraste em texto branco e detalhes/botões em Verde Neon (#00FF87).

- Estilo dos componentes: Cantos arredondados, bordas sutis com brilho discreto e cartões com efeito de vidro fosco (glassmorphism).

- Fontes modernas e limpas (inter/sans-serif).

Estrutura da Página (de cima para baixo):

1. Header / Navegação:

- Logo no canto esquerdo com o nome do ecossistema / agência.

- Botão no canto direito: "Suporte / Contato".

2. Hero Section (Apresentação do Hub):

- Título principal impactante: "Ferramentas Inteligentes para Elevar sua Performance".

- Subtítulo: "Aplicativos web (PWA) rápidos, sem necessidade de instalação por loja e com acesso vitalício."

- Badges de destaque: "✓ Acesso Imediato", "✓ Sem Mensalidades", "✓ Funciona em Qualquer Dispositivo".

3. Catálogo de Produtos (Grid Principal):

Crie uma seção de grade (grid responsivo) com cartões individuais para cada produto. Cada cartão deve conter:

- Imagem de capa / preview do aplicativo na parte superior.

- Tag/Badge de categoria (ex: Fitness, Finanças, Produtividade).

- Nome do Produto em destaque.

- Subtexto com a principal proposta de valor do aplicativo.

- Preço destacado (ex: "R$ 25,00 / Acesso Vitalício").

- Botão principal de ação: "Garantir Acesso" com efeito verde neon.

Cadastre 2 produtos iniciais no layout para demonstração:

  1. "Ironform (Gym & AI Coach)" - Categoria: Fitness & Treino

  2. "Finanças & Metas" - Categoria: Gestão Financeira

4. Seção de Benefícios do Formato PWA:

- 3 blocos explicando as vantagens dos nossos apps:

  - "Sem Download de Loja": Adicione à tela inicial direto pelo navegador.

  - "Acesso Vitalício": Pague uma única vez e use para sempre.

  - "Segurança Whop": Liberação e gestão de licença 100% automatizada.

5. Seção FAQ (Dúvidas Gerais):

- Accordion sanfonado com 3 perguntas:

  1. Como recebo meu acesso após o pagamento?

  2. Posso instalar em mais de um dispositivo?

  3. Onde insiro minha chave de licença?

6. Rodapé (Footer):

- Links para Termos de Uso, Política de Privacidade e Copyright.
